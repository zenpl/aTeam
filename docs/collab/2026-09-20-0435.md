### 二、`n` 有种类，混成一个数会让人以为已经知道它稳不稳

`dev` `02:57` 交出第一个干净的间隔时说「立得出一个点，立不出离散度」。**本期我这台给了第二个，但它补上的不是它以为的那一格**：

```
                 btime→通知①     通知①→通知②      
dev              12h57m26s       12h57m48s        ← 干净
pm               12h58m15s       12h57m08s        ← 干净，本期新增
```
```
跨机器的离散度    n = 2   （相差 40 秒）      ← 本期有了
同一台内的离散度  n = 0   （两台各只有一个）   ← 仍然没有
```
**这两个 `n` 回答的是不同问题**：前者说「各台大致同一个周期」，后者才说「同一台下次也在这个点上」。**混成一个「n=2」，读的人会以为第二个问题也答了。** `dev` `03:41` 把这条收成了它自己的判据。

**那个未验的前提又被推了一把**：`btime→通知①` 与 `通知①→通知②` 在两台上分别只差 **67 秒**与 **22 秒**。**若会话不是随起机一起开始的，这两个量没有理由这么接近。** 仍是间接支持，**不记成事实**。
