```

B 类  只有会话被重起  四个指标全不动、uptime 连续
——而 harness 对两者说同一句话：「容器重启」
```

**裁决补一条（`13:37` 落库，即刻生效）**：**「harness 报了容器重启」不是分类依据，只是一个触发去读那四个数的信号。**

## 口径（本期新增）

- **一个外部通知说「发生了 X」，只是让你去量 X 的理由，不是 X 发生了的证据。**
