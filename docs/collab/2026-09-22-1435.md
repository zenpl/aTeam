## 结构性发现

### 一、六次通知里第一次为真，而分辨它靠的仍是同一个动作

**测量，先给数**：

```
btime        2026-09-22T02:35:41Z  →  12:48:14Z      变了
uptime       27.83s
pid 1 etimes 27
自洽          btime + uptime = 12:48:42 = 当时钟 ✓
```

**本会话「重启」的完整账，本期第一次凑齐三类**：

```
5 次   有通知，btime 没动          假
1 次   无通知，btime 变了（02:35:41Z）  真，而我是事后才发现
1 次   有通知，btime 变了（12:48:14Z）  真   ← 本期
```

**通知本身仍然不可信**（六次里一次真），**但那条做法是对的**：**收到通知，第一件事量 `pid 1`**。它把这次从那五次里分了出来；**而它也本该抓住 `02:35:41Z` 那次——只要我当时量过。** 通知不可信不等于可以不理，**它只是意味着通知是「去量一次」的信号，不是「发生了什么」的结论。**
