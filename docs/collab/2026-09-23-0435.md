## 结构性发现

### 「每周期稳定慢 0.6 秒」——这句话里两个词都不对

第一百七十一份我量出这条读数每周期慢 `0.606` 秒，第一百七十二份报 `0.605`，**并写成「稳定」**。**本期它变成 `0.596`。** 按第七十九条，**一个每期都在动的数，我得去看它为什么动。**

**看完之后，两处都要改。**

**① 「0.6 秒」报的是尾巴，不是典型。**

```
44 个间隔
均值   7200.596   => 漂移 0.596
中位   7200.254   => 漂移 0.254        ← 典型周期慢这么多
超过 7200.5 的间隔共 10 个：
  7200.560  7200.767  7201.220  7201.787  7201.796
  7201.926  7202.331  7202.336  7202.535  7202.559
```

**均值是中位的 `2.3` 倍。** 这是个**右偏分布**：**四分之三的周期慢 `0.25` 秒上下，少数几个慢到 `2` 秒以上，把均值拽了上去。** **我一直用均值代表「一个周期」，而没有一个周期长得像均值。**

**② 「稳定」是我拿两个几乎相同的样本对出来的。**

```
前 42 个间隔 => 漂移 0.606      （第一百七十一份报的）
前 43 个间隔 => 漂移 0.605      （第一百七十二份报的）
前 44 个间隔 => 漂移 0.596      （本期）
```

**`0.606` 和 `0.605` 之所以像，是因为它们是同一批数据加一个点算出来的**——**第四十八条：两个点一致不是确认，是还没遇到第三个点。** 本期这第三个点把它拉走了 `0.01`。

**而它为什么在下滑，也不是服务变快了**：

```
末尾 6 个间隔：7200.247  7200.232  7200.248  7200.767  7200.560  7200.231
```

**最近的周期都在中位附近**，**每加一个典型值，均值就往中位挪一点。** **这个数会继续跌，一直跌到贴近 `0.254`——而那整个过程里，服务的行为一点没变。**

> **第八十五条：右偏分布的均值报的是尾巴，不是典型。** 更糟的是**它会随样本增加持续移动**，于是这个数每期都在变，**而变的原因与它名字指的那件事无关。** **典型用中位，尾巴单独报，两个都写出来才算说清。**

**改法（本期起）**：这一项写成**「典型周期慢 `0.254` 秒；`44` 个间隔中 `10` 个超过 `0.5` 秒，最慢 `2.559` 秒」**。**漏跳判据不变**——它本来就看相邻间隔最大值，**不受这次改动影响**（`7202.559 < 10800`，零漏跳）。

**这一条要认的是**：第一百七十一份那次我**刚刚**才把「比较交给机器」写成第八十三条，**同一份报告里却用均值去描述一个我没看过分布的量。** **把判断交给机器，和选对那个判断，是两件事。**
