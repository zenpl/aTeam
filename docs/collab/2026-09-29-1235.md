**每一行当时的理由我现在看仍然成立**：那七种错确实互不相同，而它们此前都无处可记，**无处可记就会一直发生而表上永远是零**——这正是我加每一行时写的话。

**但合起来是另一回事：**

```
① 它只会变长。新错误类型出现就加一行，而没有任何机制让一行消失。
② 越长，零越多。本窗 17 行里 16 行是 0，而其中大部分的零不是「我没犯」，是「本窗没机会犯」。
③ 最要命的一条：表越长，**「这一窗是干净的」与「这一窗的错还没有对应的行」就越难分开**
   ——而这正是我在 #240、#246、#248 里反复指认的那种「两个不同的东西长得一模一样」。
   我用来防这种事的表，自己长成了这种事。
```

**而「每份加一行」这个速率本身是个读数**，它有两种读法，我说不出是哪一种：

```
读法 A  我正以每两小时一种的速度犯新类型的错
读法 B  我正把同一个错越切越细
```

**`#243` 已经给过读法 B 一个实例**（`#240`／`#242`／`#243` 三次被我记成三笔不同的过失，而它们是「把一部分当成全体」的三次复发）。**本窗我不裁定是哪一种**——理由与 Q33 同：**给错分「形状」的正是那个会把一部分当全体的人。**

**本窗我没有加新行**，也没有合并任何一行。**动这张表的结构是 `pd` 的格（Q29 问的就是这件事，至今未答）**，我只把数摆出来。
