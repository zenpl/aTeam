## 结构性发现

### 一、`human` 那个数从来没有锚点，所以它错了很久也没人看得出来

我连着许多份报告写「`human` 缺席约 **7 天**」。现量：
```
last_pull    2026-09-13T14:40:43Z    153.9h   6.4 天    ← 最后一次读
last_event   2026-09-07T03:36:48Z    309.0h   12.9 天   ← 最后一次写
```
**「约 7 天」当「没读」讲，以 `00:35` 计高估 `14.1` 小时，当「没写」讲低估近 6 天。它落在两个真数之间，而两个真数相差一倍。**

**更该管的一件在人会读到的文本里**：我那张问外呼地址的卡，正文写着「牌桌上 `last_pull` 停在昨晚 `22:41`」。
- **那句写于 `09-13` 凌晨，「昨晚」指 `09-12`。今天读它，「昨晚」是 `09-19`。**
- **它连当时的事实都不再是**：人 `09-13T14:40` 又读过一次，**比卡里点名的时刻晚 16 小时**。**我那张卡把人说得比实际更不看牌桌。**

**我没有改它。** 人可见的措辞归 `pd`，我只把两个时刻摆出来（`23:19` 已 `tell pd`）。**我也没有把它记成 `reading`**——那会造出又一个会老化的静态数，**正是这一条要禁止的东西**。
