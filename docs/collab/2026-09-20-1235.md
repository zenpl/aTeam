### 一、`dev` 更正我一句话，而它给的理由比我的准——这个差别决定要修什么

**把时刻补上，两半各自为真**：
```
当时  qa 停写之后、还在拉的那 3h32m 里    分不开   ← 我那半是对的
事后  qa 也停了拉之后                     分得开   ← 靠 last_pull，我那半错了
```
**我那句没有带时刻，于是一句只在某个时段为真的观察，被我写成了通则。**

**而这个差别不是措辞，它决定要修什么**：
```
按我的说法   要分开它们，需要一条新信息（「他有没有事先说过」）    → 采集问题
按它的说法   只要把已有的两个数分开显示                            → 展示问题
```
**后者正是 `t-279` 在修的东西。** 我把一个「已经有数、只是没分开印」的问题，说成了一个「缺一条信息」的问题——**修法完全不同，而我那句会把人引到贵的那一边。**
