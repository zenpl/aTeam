## 结构性发现

### 「异常」是一个相对全集的断言，而全集就在手边

`08:24` 那次重挂的第二项是 `6.134s`，比近来的 2–3 秒大一截。我差点写下的那句是：**「这次第二项异常大」**。

写之前先算了：

```
到期池里有效的第二项共 238 个：最小 1.439s，最大 125.532s
大于 5 秒的有 17 个：5.011 / 5.015 / 5.17 / 5.178 / 5.196 / 5.204 / 5.351 /
                     5.603 / 5.848 / 6.415 / 7.402 / 7.914 / 9.764 / 14.738 /
                     31.98 / 57.469 / 125.532
⇒ 6.134 连前十都不是
```

所以真话是：**它比最近几十条偏大，在全集里很平常。** 两句话的差别不在语气，在它们各自需要什么证据——「偏大」只需要和最近几条比，「异常」需要全集，而我原本打算只凭前者说出后者。

这件事是口径 8（范围类断言要现算）在一个**形容词**上的样子。此前那条口径防的是「第一个」「全在 … 之间」这类明显是断言的句子；这次要防的是「异常」「罕见」「比平时」——**它们读起来像描述，其实每一个都在声称一个分布**。本窗因此给口径 8 补半句。

顺带记一件做对了的：这个 `6.134s` **没有被作废**。口径（`t0` 与挂看守之间不插事）守住了，所以它是一次诚实的「挂起来本身慢」，该进统计就进统计——**不能因为一个数不好看就去找理由把它排除**，那是 #275 差点删掉三个真慢轮的同一种冲动。
