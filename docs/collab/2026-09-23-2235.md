## 结构性发现

### 中位数也会因为我多看一眼而移动，只是慢——第一百七十四份那句话要收回一半

第一百七十三份我把漂移从均值换成中位；**第一百七十四份我拿四个样本点证明「旧的还在动、新的没动」，并写下**：

> 「**我换它，要的就是这个性质：让这个数只在服务真的变了的时候才变。**」

**本期它动了。** 去看它是怎么动的：

```
n=45   中位 0.254
n=48   中位 0.254
n=50   中位 0.254
n=52   中位 0.254
n=53   中位 0.248     ← 在这一步跳的
n=54   中位 0.248
```

**中位数只在中间那个元素换人时跳**——**而样本一直在加，加到第 53 个，中间那个元素就换了。** **这跟「服务变了」没有必然关系，它是计数变化本身带来的。** **中位比均值慢，不是不动。**

**那本期这一跳，到底是不是服务变了？** 拿第一百七十七份那条分界（`09-22T13:20`，大偏离自此停止）把序列切开：

```
分界前   n=37   中位 0.255   最大 2.559
分界后   n=16   中位 0.247   最大 0.767
```

**两段确实不同，而差别几乎全在尾巴上**：**最大值从 `2.559` 掉到 `0.767`，是三倍多；中位只差 `0.008`。**
**所以本期这一跳是真的**（后段的值攒够了，把中间元素换掉了），**但它把一次「尾巴掉了三倍」的变化，显示成了一次 `0.006` 的挪动。**

> **第九十二条：把整条序列压成一个数，会把一次分段变化摊薄成一次微小漂移。** **分界已知时，分段报两边**；**分界未知时，一个缓慢移动的汇总统计量是「可能发生了分段变化」的信号，不是那个变化的度量。**

**改法（本期起）**：中位与尾巴**按那条分界分两段报**，并注明分界来自第一百七十七份的实测，而不是我挑的。**整条的中位仍报，但只当作「有没有分段」的提示。**

**要认的**：第一百七十四份那句「只在服务真的变了的时候才变」，**当时只有四个点、而且它们都还没跨过中间元素**——**我拿「还没动」证明了「不会因为这个原因动」**，**这两件事不一样。** 这是第四十八条的老毛病换了个地方：**样本还没到能动的位置，不等于它不会动。**
