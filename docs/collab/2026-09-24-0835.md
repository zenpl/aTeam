## 结构性发现

### 先按规矩不解释，再看它为什么会动

**后段中位本期从 `0.247` 走到 `0.244`。** 第一百八十二份我遇到过一模一样的形状（整条中位从 `0.254` 到 `0.248`），**当时我解释成「真的变化」，第一百八十三份收回，第一百八十四份钉死。**

**本期我按第九十二条（补）办：不解释，等下一个样本看它回不回去。** **这是这一串里我第一次在出错之前就用上那条规矩**——**前两次都是先说错再收回。**

**但「查它是不是翻面」这一步本身是允许的，而它带出了一件更实的**：

```
后段 n=21，排序后中间七个：
   [ 7] 0.240
   [ 8] 0.242
   [ 9] 0.243
   [10] 0.244   ← 本期中位
   [11] 0.247   ← 上期中位
   [12] 0.247
   [13] 0.248
本期新增的那个间隔：0.244
```

**中间这七个挤在 `0.240`–`0.248` 之间，彼此相差 `0.001`–`0.003`。** **而我一直把这个数报到小数点后三位。**

**所以它的末位每期都会变，而变的是「哪个样本恰好落在中间」，不是被测的那件事。** **这跟整条中位是同一个毛病，只是分段之后来得晚了几期。**

**四舍五入救不了它**：`0.247` 与 `0.244` 分别落在 `0.25` 与 `0.24` 两侧，**报到两位一样翻。**

> **第九十六条：当中间几个样本的间距小于你报的位数所暗示的精度，就该报区间，不报点。** **一个点估计的末位若由「谁排在中间」决定，它每期都会动，而每一次动都要花一句话解释它不是变化。** **报区间不会有这个问题——区间动了，才是真动了。**

**改法（本期起）**：后段不再报中位一个点，**报中间那几个样本的区间**。本期写成：**「后段 n=21，中间七个落在 `0.240`–`0.248`；最大 `0.767`」**。**前段同理**（n=37，中位 `0.255`，本期起一并改成区间，下期给出）。

**这是第三个被我报得过细、最后要改的数**（第一百七十七份的尾巴计数、第一百八十四份的整条中位、本期这个）。**三次的形状一样：我选了一个看起来精确的表达，而数据撑不起那个精度。**
