### 换上来的两个数，第一次被重算，两个都自洽

**① 痕迹合计——用「差值」验。**

```

本期实测（同一条命令）                       14295
差                                          119
本窗看守轮数（独立量的：按 === 行的时间戳分窗）  119
```

**两个数来自同一个文件，但走的是两条不同的路**：一条是**整文件行数相减**，另一条是**按时间戳筛出本窗再数**。**它们相等，说明这两期之间没有第三方在动这个文件，也说明分窗那把尺子在本窗里没有漏行。**

**② 服务预警连续相同——用「跨度」验。**

```
连续相同条数     41

该读数的节奏     两小时一条（早先量过）
推论             (41 − 1) × 2h = 80h   与实测跨度相等
```

**相等意味着这 41 条里一次都没有漏跳**——**包括中间那次宿主重启**（`12:48:14Z`）。**这一条顺带补上了上一份的一个空白**：上一份我只说「`13:20:16` 那条准时到」，**那是一个点；本期这个等式管的是整条。**
